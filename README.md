## The joke

## How it works

`main.py` (Python 3, standard library only) writes the one-line joke to `/output/entry.txt`, self-checking the gate first: 1–200 UTF-8 characters, not only whitespace, a single line.

```sh
python3 main.py
cat /output/entry.txt
```
